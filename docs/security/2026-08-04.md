## Threat Model

LeonOS 4 的关键边界包括 Ring-3 到内核系统调用、受信任桌面代理、持久化配置、认证会话和不受信任网络输入。

### Assets

- 内核内存与调度器状态
- 认证会话与管理角色
- 系统配置和用户数据
- 网络流量与浏览器凭据

### Trust Boundaries

- Ring-3 到 Ring-0 系统调用
- 客户端到桌面/系统服务请求
- 二层/三层网络到协议状态机
- HTTPS/HTTP 与浏览器认证状态

### Attacker Capabilities

- 低权限本机程序可调用公开系统接口
- 同一二层网络节点可发送网络帧
- 远程端点可提供 HTTP 响应和重定向

### Security Objectives

- 防止用户态破坏内核内存
- 确保特权操作有明确授权
- 保持下载和凭据的传输完整性
- 验证网络状态转换

### Assumptions

- 固件、物理磁盘篡改和构建签名者不在本次常规应用威胁边界内。
- 隔离 VM 和网络动态验证留待后续。
