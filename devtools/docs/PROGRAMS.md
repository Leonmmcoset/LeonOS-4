# 程序开发约定

## 进程和生命周期

应用启动后应尽快完成窗口/终端初始化，再进入事件循环。不要在主线程启动时
同步读取大文件、解压词库或执行网络请求；将工作拆成小块，在每块之间调用
`sched_yield()` 或使用有界等待。

父进程通过 `leonos_launch_argv()` 或 `leonos_pty_spawn_argv()` 启动子程序，
并使用 `wait4()` 回收。应用退出路径要关闭窗口、文件描述符、socket、PTY 和
PNG 缓冲，避免资源泄漏。

## GUI 约定

- 所有绘制都写入自己的像素缓冲，再调用 `leonos_gui_present_window()`。
- 响应 `RESIZE`、`THEME_CHANGED` 和 `CLOSE` 事件；窗口尺寸来自事件时先做
  乘法溢出检查。
- 不要依赖物理 framebuffer、固定分辨率或固定字体文件名。
- 任务栏隐藏、无边框和全屏属于窗口状态，退出前恢复用户可见的桌面状态。

## 输入和安全

普通编辑框接入 InputM；密码、登录、授权、OOBE 和浏览器密码控件必须使用安全
上下文。不要在日志、崩溃文本或 API 包元数据中输出密码、Token、cookie 或完整
用户路径。

键盘事件使用 `keycode` 和 `pressed`，不要把扫描码直接当作 ASCII。文本输入应
优先消费 InputM 提交的 UTF-8；未消费的退格、回车、方向键交给 UI 状态处理器。

## 文件、网络和并发

- 处理用户路径前拒绝空路径、绝对路径穿越和 `..`，并检查 `stat` 类型。
- 读写循环必须支持短读/短写和负返回值。
- 网络请求设置超时、限制响应大小，校验证书和 HTTP 状态。
- 不要在窗口服务器、状态栏或输入法回调中执行长时间磁盘 I/O；后台工作完成后
  通过事件或短消息通知 UI。

## 调试建议

调试输出使用带程序名前缀的 `printf`，并避免每帧打印。遇到“应用无窗口”时按
顺序检查：`leonos_gui_connect()` 返回值、窗口创建结果、事件等待返回值、像素
缓冲尺寸和 `present` 返回值。遇到“命令无输出”时检查 PTY 绑定、短写处理、
ANSI 控制序列和子进程 `wait4` 回收。
