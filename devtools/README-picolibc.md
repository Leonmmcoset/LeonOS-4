# Picolibc in the LeonOS SDK

The SDK ships two static archives. `lib/leonos.a` supplies LeonOS system-call,
GUI, and runtime adapters. `lib/libc.a` is the Picolibc 1.8.12 ISO C library.
They must be linked together in a linker group; the supplied Makefile already
does that.

The SDK's ISO C headers are the matching headers generated by Picolibc. LeonOS
headers remain under `include/leonos/`. Do not mix these files or either
archive with a different LeonOS SDK release.

`-mgeneral-regs-only` is the default SDK compile mode for ordinary applications.
The kernel saves and restores x87/SSE state during user-task switches, so an
application that genuinely needs the standard x86-64 floating-point ABI may
opt out of that flag consistently for all of its objects. Lua does this to
match Picolibc and Clang floating-point helpers. The configured Picolibc
formatting default is still integer.

`THIRD_PARTY/PICOLIBC-COPYING` contains Picolibc's complete upstream copyright
and license notices. `THIRD_PARTY/PICOLIBC-VERSION.txt` records the exact source
revision used for this SDK archive.

From WSL, regenerate the SDK with `python3 build.py run sdk`.
